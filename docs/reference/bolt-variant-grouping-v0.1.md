# 螺栓标准类型与规格聚合规则 v0.1

更新日期：2026-08-20

## 目标

物料采购页面不再把同一螺栓类型的每个 SKU 平铺成独立卡片。目录先展示标准类型，用户点开后按实际存在的属性组合选择，最后解析到唯一 ERPNext Item。

## 判定规则

- 六角、双头、绞制孔、预埋、环向/纵向、带孔等名称证据用于确定标准类型。
- 强度等级、材质、表面处理和供货范围是 SKU 属性，不单独作为螺栓类型。
- 只有“螺栓”或“高强度螺栓/螺丝”但没有头型、结构或用途证据时，归入“头型待识别螺栓”，不猜测为六角螺栓。
- 页面选择器合并采购必选属性与价格/适配关键属性；全部选择后必须只剩一个现有 SKU，才允许加入申请。
- 不生成笛卡尔积，不创建目录中不存在的规格。

## 编码与 ERPNext 边界

标准类型使用 GPC Brick 下每层追加两位的目录编码。已经同步到 ERPNext、并可能被历史单据引用的 Item Code 保持稳定；本次只修正本地分类路径和采购聚合体验，不静默重编号、不复制 Item。后续若确需迁移既有 Item Code，必须单独做引用检查、预览、确认、写后回读和回滚方案。

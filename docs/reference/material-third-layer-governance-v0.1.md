# 物料三级名称治理规定 v0.1

本文用于指导物料主数据的第三层治理：

```text
一级类目 -> 二级物料族 -> 三级物料名称 -> SKU 明细
```

目标是让三级物料名称像商品目录一样稳定，SKU 明细像采购规格一样精确。

## 一、三级名称只放什么

三级物料名称只保留物料的核心商品类型、核心形态或稳定功能。

可以进入三级名称：

- 商品类型：球阀、蝶阀、弯头、三通、膨胀螺栓、内六角螺丝。
- 核心形态：直接/直通、异径接头/大小头、堵头/管帽、补心。
- 稳定功能：止回阀、安全阀、减压阀、排气阀、混水阀。
- 行业稳定专名：管片螺栓、鱼尾螺栓、Y型过滤器。

不应进入三级名称：

- 材质：PPR、PVC、UPVC、不锈钢、铜、铝合金、橡胶。
- 表面处理：镀锌、发黑、喷塑。
- 连接方式：内丝、外丝、法兰、沟槽、焊接、热熔、胶接、宝塔。
- 规格尺寸：DN50、4分、M8*45、32*25、90度。
- 品牌型号：公元、埃美柯、A28H-64。
- 驱动或结构属性：电动、弹簧式、两片式、六角、加厚。
- 使用场景：高压、液压、补水、冷热水、热水器。

这些信息必须下压到 SKU 的 `必填规格` 或 `辅助规格`。

## 二、SKU 规格怎么写

SKU 规格要尽量保留原始信息，不凭空删除。

常见字段：

```text
规格/公称直径/直径/管径
材质
连接方式
表面处理
角度
变径规格
压力等级/公称压力
结构
驱动方式
用途/工况
品牌
型号
执行标准
```

如果原始名称里含有隐含信息，应结构化追加到 `assumed_specs`，由生成脚本合并进 `required_specs`。例如：

```text
PPR90度弯头 -> 三级名称：弯头；assumed_specs：材质：PPR；角度：90度
不锈钢内丝球阀 -> 三级名称：球阀；assumed_specs：材质：不锈钢；连接方式：内丝
镀锌外丝六角直接 -> 三级名称：直接/直通；assumed_specs：表面处理：镀锌；连接方式：外丝；外部形状：六角
```

如果关键规格缺失，不要为了好看而编造安全关键参数，例如压力等级、材质牌号、执行标准、壁厚、电压等。可以在 `next_action` 里要求采购前确认。

## 三、决策类型

`decision` 使用以下值：

- `脱水保留`：原三级名称已经是稳定商品名，只需下压部分属性。
- `三级名称脱水`：原名称包含材质/连接/规格等污染词，治理后收敛为核心商品名。
- `三级名称修正`：原名称过泛、错误或同义词，需要改成更准确商品名。
- `复核`：信息不足，暂时给出低风险近似名称，但使用前必须确认。
- `移出`：二级物料族不对，需要移动到新的物料族。

## 四、置信度

`confidence` 使用：

- `high`：名称、规格或别名明确支持判断。
- `medium`：大概率正确，但存在现场叫法或缺少部分规格。
- `low`：只能临时归类，使用前必须确认。

## 五、输出表字段

每个三级治理批次输出 TSV，字段固定：

```text
item_code
current_item_name
current_required_specs
current_uom
target_top_category
target_second_layer_family
target_third_layer_name
decision
confidence
assumed_specs
manual_judgment
next_action
```

## 六、验收标准

- 输入物料族的 SKU 必须 100% 覆盖，不漏、不多、不重复。
- 三级名称数量应明显少于原始名称数量，但不能为了压缩而合并不同商品。
- 材质、连接方式、尺寸、角度、压力、品牌型号不得继续污染三级名称。
- 疑似不属于当前物料族的物料，应使用 `移出` 并指定目标二级物料族。
- 低置信项必须写明为什么低置信，以及采购/建档前要确认什么。

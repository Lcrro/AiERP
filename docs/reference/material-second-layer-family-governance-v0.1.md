# 物料第二层物料族治理 v0.1

本文件用于把当前物料主数据的第二层先定住。我们已经有相对稳定的一级类目，下一步不直接清洗所有 SKU，而是先建立每个一级类目下允许出现的“物料族”骨架。

## 1. 分层口径

本项目采用四级联动：

```text
一级类目 -> 二级物料族 -> 三级物料名称 -> 四级 SKU 明细
```

以 `M8*45 内六角螺丝` 为例：

```text
一级类目：紧固件与连接件
二级物料族：螺丝/螺栓
三级物料名称：内六角螺丝
四级 SKU 明细：M8*45；材质：碳钢；强度等级：12.9；表面处理：发黑
```

第二层不是最终商品名，也不是完整规格。第二层只回答一个问题：这批物料共享哪套规格模板和选型逻辑。

## 2. 第二层物料族的判断规则

一个词可以作为物料族，必须满足至少三个条件：

1. 能承载一套稳定的规格模板。
2. 能聚合多个具体物料名称。
3. 对采购、仓库、项目、Agent 检索有实际帮助。
4. 不是纯材质、纯尺寸、纯品牌、纯项目用途。

正例：

- `螺丝/螺栓`：可聚合内六角螺丝、自攻螺丝、六角螺栓等。
- `管材`：可聚合 PVC 管、PPR 管、镀锌钢管等。
- `阀门`：可聚合球阀、闸阀、止回阀等。
- `手套`：可聚合帆布手套、乳胶手套、焊工手套等。

反例：

- `不锈钢`：材质，不是物料族。
- `高压`：工况/性能，不是物料族。
- `M8*45`：规格，不是物料族。
- `常用材料`：采购频率，不是物料族。
- `张工急用`：业务场景，不是物料族。

## 3. 第二层和第三层的边界

第二层应比一级类目更具体，但不能细到每个商品名。

| 层级 | 示例 | 说明 |
|---|---|---|
| 一级类目 | 紧固件与连接件 | 财务、采购统计层 |
| 二级物料族 | 螺丝/螺栓 | 搜索聚合和规格模板层 |
| 三级物料名称 | 内六角螺丝 | 采购员能一眼识别的商品名 |
| 四级 SKU 明细 | M8*45；12.9级；发黑 | 可采购、可库存的最小规格 |

所以截图中的 `螺丝 -> 螺丝 -> M8*45；头型/驱动：内六角` 应该改成：

```text
紧固件与连接件 -> 螺丝/螺栓 -> 内六角螺丝 -> M8*45；材质；强度等级；表面处理
```

## 4. 第二层治理的阶段目标

当前数据中，一级类目约 20 个，但物料族有 800 多个，说明二级层过碎。v0.1 的目标是先建立目标族表：

```text
data/material_master/governance_v0_2/material_second_layer_families_v0_1.tsv
```

这张表不直接写 ERPNext，也不覆盖正式主表。它只用于后续三件事：

1. 判断当前物料族是否应该合并、拆分或保留。
2. 为第三层物料名称治理提供范围。
3. 为每个物料族定义必填规格模板。

## 5. 治理优先级

第二层先按业务价值治理，不追求全量一次完成：

1. 管材管件阀门：数量最多，项目施工影响大。
2. 紧固件与连接件：当前混乱集中，但先定族，不再细抠每个螺丝规格。
3. 液压气动：高压管路、胶管、接头选型风险高。
4. 电气电料：安全风险和型号规范要求高。
5. 吊装索具、安全消防：安全责任重，必须有清晰规格模板。

长尾后勤、办公、非标加工件允许继续保留 `needs_review`，等实际采购触发时再治理。

## 6. 后续执行方式

第二层定住后，每个物料族再进入第三层治理，例如：

```text
螺丝/螺栓 -> 内六角螺丝、自攻螺丝、六角螺栓、钻尾螺丝
管材 -> PVC 管、PPR 管、PE 管、镀锌钢管
阀门 -> 球阀、闸阀、止回阀、蝶阀、电磁阀
手套 -> 帆布手套、乳胶手套、焊工手套、浸胶手套
```

第三层之后才进入 SKU 明细补全。缺材质、强度、压力等级、品牌型号时，不允许 AI 猜默认值，只允许标记为采购前必问。

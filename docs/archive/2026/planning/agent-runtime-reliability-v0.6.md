## 验收指标

- 业务写操作不由模型直接拼底层 ToolCall。
- 100% 写操作经过不可变确认。
- 100% 成功写操作经过 ERPNext 回读。
- 不存在未经 Resolver 核对的 Link 主键。
- 同一测试集可重复运行并输出逐案例轨迹。
- 新增业务模块时不扩大核心系统提示词，只增加独立能力包和测试。

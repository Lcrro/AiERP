# 物料标准类目表 v0.1

本文件用于把现有物料主数据重新归类。分类只回答一个问题：

```text
这个物料本质上是什么？
```

不要把以下信息放进分类名：

- 是否耗材、是否常用品、是否低值易耗
- 哪个部门使用、哪个项目使用
- 是否需要询价、是否需要确认规格
- 是否库存常备、是否临时采购

这些信息后续应放到独立字段，例如 `item_nature`、`procurement_policy`、`agent_use_policy`。

## 分类原则

1. 同一物料只能落入一个标准分类。
2. 一级类目保持稳定，二级类目描述物料族，必要时三级类目描述细分类型。
3. 土名、旧分组、部门叫法只能作为别名或检索词，不作为标准分类。
4. “耗材”不是物料分类，只能作为物料性质。
5. “工程材料、建材、建筑施工耗材”这类宽泛旧类目应拆到更具体标准类目。
6. 若物料需要靠规格区分 SKU，分类不要再继续拆规格。

## 常见旧分类归并规则

| 旧分类/旧口径 | 标准处理 |
|---|---|
| 劳保耗材 | 不保留为分类；按实物归入 `劳保防护`、`清洁办公后勤`、`包装覆盖周转` 等 |
| 劳保用品 | 归入 `劳保防护` |
| 工具器具 | 根据实物归入 `工具量具`、`电动气动工具`、`工具耗材` |
| 工具 | 根据实物归入 `工具量具`、`电动气动工具`、`工具耗材` |
| 工具耗材 | 保留为标准一级类目，但只放钻头、切割片、刷子等工具消耗品 |
| 电气、电气材料 | 统一归入 `电气电料`，弱电监控类归入 `弱电安防` |
| 工程材料、建筑材料、建材 | 不直接沿用；拆入 `建筑材料`、`管材管件阀门`、`金属材料` 等 |
| 五金、五金备件 | 不直接沿用；拆入 `紧固件与连接件`、`工具量具`、`清洁办公后勤` 等 |
| 管件、PPR管件、PVC管件 | 统一归入 `管材管件阀门` 下的相应二级类目 |
| 钢材、原材料/型钢、金属材料/型材 | 统一归入 `金属材料` |
| 化工耗材、油漆涂料、胶粘剂 | 统一归入 `化工胶粘涂料` |

## 子代理输出要求

每个同名物料组输出一行，字段如下：

```text
group_id
item_name
old_groups
sku_count
suggested_category
suggested_subcategory
needs_split
split_basis
confidence
reason
```

字段说明：

- `suggested_category` 必须使用本文件定义的一级类目。
- `suggested_subcategory` 优先使用推荐二级类目；确实不匹配时可填写新的二级类目，但必须在 `reason` 说明。
- `needs_split` 只能是 `yes` 或 `no`。若同名物料实际包含不同物料族，例如“接头”同时包含液压接头和水管接头，填 `yes`。
- `split_basis` 填拆分依据，例如“按材质/用途/规格/旧分组拆分”；不需要拆分则填空。
- `confidence` 只能是 `high`、`medium`、`low`。
- `reason` 要短，说明为什么这样归类；如果旧分类明显错误，应指出。

# Standard Item Catalog From Purchase Review

This document describes the derived catalog exported from the archived source record
`../archive/2026/reference/purchase-material-standardization.md`.

The source review is a row-by-row human/model standardization of the 2024 purchase list. The exported files are not raw purchase records; they are a first draft of material master data for search, deduplication, and later ERPNext import.

## Files

| File | Purpose |
| --- | --- |
| `data/material_purchase_2024/standard_item_catalog_from_review.csv` | Deduplicated standard item candidates extracted from rows marked `可建档`, `可建档-低精度`, `可建档-定制件`, `可建档-加工件`, `可合并`, or `可合并/单位待统一`. |
| `data/material_purchase_2024/item_aliases_from_review.csv` | Raw purchase names mapped to proposed standard item codes. Use this as the first alias table for item search. |
| `data/material_purchase_2024/manual_review_queue_from_review.csv` | Rows that still need human clarification before they can become reliable material master records. |
| `data/material_purchase_2024/non_stock_services_from_review.csv` | Services, fees, repairs, freight, and non-material rows that should not become stock items. |

## Catalog Fields

| Field | Meaning |
| --- | --- |
| `proposed_item_code` | Temporary catalog code generated from the review export, e.g. `REVIEW-MAT-00001`. This is not the final ERPNext item code. |
| `standard_name` | Suggested clean material name. |
| `item_group` | Suggested material group path. |
| `specs` | Structured attributes extracted from the raw purchase name. |
| `unit` | Original purchase unit preserved from review. |
| `source_count` | Number of reviewed rows merged into this candidate. |
| `source_statuses` | Review statuses observed among merged rows. |
| `alias_names` | Original names that should be searchable aliases. |
| `source_rows` | Original Excel row references. |
| `notes` | Missing fields, warnings, or confirmation questions from the review. |

## How To Use

1. Use `standard_item_catalog_from_review.csv` as the first seed set for the material search tool.
2. Use `item_aliases_from_review.csv` to match local names, slang, typos, and supplier wording to standard items.
3. Keep `manual_review_queue_from_review.csv` outside automatic creation; these rows should trigger clarification questions.
4. Keep `non_stock_services_from_review.csv` as service/expense references, not inventory items.
5. Before importing into ERPNext, replace `REVIEW-MAT-*` with final codes generated by the item coding engine.

## Important Rules

- Do not let the LLM invent final ERPNext item codes.
- Do not auto-create rows whose status contains `待确认`.
- Do not create inventory items for freight, repair labor, installation labor, garbage removal, or other service rows.
- Safety-critical categories require manual review before auto-creation: lifting gear, fire equipment, safety ropes, life jackets, pressure instruments, hazardous chemicals.
- Deduplication should preserve all aliases, because aliases are critical for later natural-language retrieval.

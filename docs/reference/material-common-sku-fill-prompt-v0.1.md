# 常用 SKU 默认规格补全提示词 v0.1

## 任务

读取指定 TSV 中的 B/C 级 SKU 草案，为每一条补全一个“最常用默认规格”的可用 SKU。

目标不是还原历史采购真实规格，而是先给系统准备一批常用基础物料，减少员工后续新增物料的次数。

如果员工需要其他规格，以后再新增物料。

## 输入字段

```text
draft_sku_id
draft_item_code
放行等级
标准名称
必填规格
辅助规格
标准分组
标准单位
别名/土名
missing_specs
整理依据
```

## 输出字段

输出 TSV，字段固定为：

```text
draft_sku_id
draft_item_code
原放行等级
标准名称
标准分组
标准单位
原必填规格
补全后必填规格
补充规格项
默认假设
适用范围
风险等级
建议导入状态
员工选择提示
补全依据
```

## 核心口径

- 每一行都必须输出一条常用默认 SKU。
- 不要输出“待补”“缺失”“不详”“需确认”作为补全后规格。
- 可以基于行业常见口径补默认值，但必须在“默认假设”里说明。
- 不要假装默认值就是原始真实值；它只是为了先放入系统的常用基础 SKU。
- 保留原规格里的有效信息，在此基础上补齐缺少字段。
- 标准名称不要随意改，主要改“补全后必填规格”。
- 单位优先保持输入单位，明显不合理才在依据里说明，但本任务不改单位。
- 如果某物料有较高安全/适配风险，也仍然补一个常用默认 SKU，但风险等级必须标为“高”，员工选择提示必须提醒确认。

## 风险等级

- 低：办公、清洁、普通低值耗材、普通工具、小五金。
- 中：普通电气、普通建材、普通管件、普通紧固件、普通劳保。
- 高：承压管件、高压胶管、液压接头、阀门、消防、电气保护元件、设备备件、吊装索具、定制加工件。

## 建议导入状态

- `seed_import_ready`：可作为常用默认 SKU 导入 sandbox。
- `seed_confirm_before_import`：可作为常用默认 SKU，但导入前最好由业务确认一次。

## 示例

输入：

```text
门锁 / 用途：办公室门 / missing_specs=型号；规格；锁体型号
```

输出：

```text
补全后必填规格：用途：办公室门；类型：执手锁；锁体规格：常用 50 锁体；开向：通用可调；材质：锌合金；颜色：银色
默认假设：按办公室木门/金属门常用执手锁配置，不代表原采购真实型号。
员工选择提示：默认办公室门常用锁；如需防火门锁、玻璃门锁、特定锁体或特定开向，请新增物料。
```

## 输出质量要求

- 行数必须等于输入行数。
- 每行必须有“补全后必填规格”。
- “补全后必填规格”必须比“原必填规格”更完整。
- “默认假设”和“员工选择提示”必须能让员工理解这是默认规格。
- 不写入 ERPNext，不修改源文件。

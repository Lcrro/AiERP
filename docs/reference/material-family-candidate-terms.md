# 物料族候选词清单

本文件说明如何从现有物料名称中发现“可整合成物料族”的候选词。

核心思路：

```text
很多标准名称共享同一个核心词，例如 钻头、手套、弯头、螺丝。
这些核心词往往不是 SKU 本身，而是物料族。
材质、用途、柄型、规格、连接方式等应作为族内属性。
```

## 输出文件

候选清单：

```text
data/material_master/reclassification/material_family_candidate_terms.tsv
```

统计摘要：

```text
data/material_master/reclassification/material_family_candidate_terms_summary.json
```

生成命令：

```powershell
python scripts\build_material_family_candidate_terms.py
```

## 字段说明

| 字段 | 说明 |
|---|---|
| 候选词 | 从物料名称或当前物料族中提取出的共享核心词 |
| 建议物料族 | 如果固化，建议使用的物料族名称 |
| 处理建议 | 是否可优先固化、人工复核、按用途拆分，或暂作检索/属性候选 |
| 置信度 | `high`、`medium`、`low` |
| 覆盖SKU数 | 命中该候选词的 SKU 数 |
| 覆盖标准名称数 | 命中的不同标准名称数量 |
| 当前物料族数 | 当前浏览层中这些物料分散成多少族 |
| 是否跨一级类目 | 是否跨越多个一级类目 |
| 主要分类 | 命中物料当前所在分类及数量 |
| 当前物料族 | 当前浏览层物料族样例 |
| 样例标准名称 | 命中的标准名称样例 |
| 样例SKU | 命中的 SKU 样例 |
| 说明 | 判断依据或风险提示 |

## 需要拆分的候选

这些词很高频，但不能直接粗暴合成一个族：

| 候选词 | 原因 |
|---|---|
| 接头 | 横跨液压、气动、水暖、消防、电气防水接头 |
| 螺丝 | 包含普通螺丝、膨胀螺丝、螺丝刀、花篮螺丝等 |
| 弯头 | 包含水暖弯头、液压弯头、定制加工弯头 |
| 三通 | 包含水暖三通、液压三通、气管三通 |
| 泵 | 包含整机、备件、控制开关和工具干扰 |
| 管卡 | 包含标准管卡、抱箍、定制卡箍组件 |
| 垫片 | 包含金属垫片、橡胶垫片、法兰垫片、定制垫片 |

## 使用建议

1. 先从 `可优先固化为物料族` 的候选开始，逐个做规则样板。
2. 对 `可作为候选，但需按用途/系统拆分` 的词，不要直接合并，要先确定拆分规则。
3. 高频但更像材质、品牌、特征的词，例如不锈钢、镀锌、加厚，不应作为物料族。
4. 每次固化一个族后，只更新浏览层规则和候选清单，不直接写 ERPNext。

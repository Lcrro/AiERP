# PPR 接头多规格归并规则 v0.1

更新时间：2026-08-28

## 归并范围

商城与物料分类工作台把以下已发生物料统一展示为标准类型“PPR接头”：

- PPR 弯头；
- PPR 异径三通；
- PPR 等径三通；
- PPR 直接接头；
- PPR 活接头。

PPR 给水管和 PPR 截止阀不属于接头，继续保留独立标准类型和独立库存 SKU。

## 选择与编码规则

用户先选择“接头类型”，系统再按需要显示后续可变规格。现有五个 SKU 每种接头类型各有一个实际发生规格，因此选定接头类型后即可解析到唯一物料编码。

统一的 SKU 身份字段为：

1. 接头类型；
2. 规格；
3. 公称压力；
4. 材质。

规格采用紧凑表达：弯头为“口径×角度”，异径三通为“主管口径×支管口径”，其余接头为公称口径。只允许已存在的属性组合解析到 SKU，不生成属性笛卡尔积。

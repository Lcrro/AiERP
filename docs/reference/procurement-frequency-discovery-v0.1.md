# 实际采购清单高频物料发现 v0.1

## 目的

本任务只读分析 `龙华项目物料待导入清单.xlsx` 的 `实际采购清单`，发现“同一标准类型的别名和规格变体”，并按采购频次排序。它不是物料发布、SKU合并或 ERPNext 写入任务。

```text
原始采购行
→ 规范名称和单位
→ 安全识别标准类型头
→ 聚合别名与规格变体
→ 输出频次、规格数、别名数和金额
→ 疑似相似项进入人工复核
```

## 口径

- `line_count`：原始非空材料行数，保留作审计事实；
- `distinct_event_count_approx`：按日期、工序、名称和单位去重的近似采购事件数，避免重复导出行过度放大频次；
- `alias_count`：同一聚类中的不同原始叫法；
- `variant_count`：同一标准类型下不同规格/剩余属性表达的数量；
- `quantity_by_uom`：按规范化单位分别汇总，禁止把件、米、千克直接相加；
- `market_value_sum`：有数量和单价的行的金额合计；
- `integration_priority_score`：用于排序的透明启发式分数，不是分类真值。

输出同时保留 `frequency_rank`（按近似采购事件优先）和 `integration_rank`（按频次、别名和规格丰富度优先），避免把“买得最多”和“最值得做多属性整合”混成一个指标。

不同规格只在“标准类型”层聚合，具体 SKU 不会被合并。无法可靠识别标准类型头的项目保持独立，不能因为文字相似就自动归组。

## 运行

```powershell
python scripts/material_master/discover_procurement_frequency.py `
  --source "$HOME\Downloads\龙华项目物料待导入清单.xlsx"
```

输出目录默认为 `.runtime/material-master/frequency-discovery/`：

- `discovery-summary.json`：总量、门禁统计和运行版本；
- `source-rows.jsonl`：每一条原始行及规范化字段；
- `clusters.jsonl`：标准类型候选、频次、别名、规格和数量；
- `fuzzy-review-candidates.jsonl`：仅供人工复核的相似候选，不自动合并。

## 首轮全量结果（2026-08-31）

| 指标 | 结果 |
|---|---:|
| 实际采购行 | 1,273 |
| 不同原始名称 | 991 |
| 安全聚类 | 40 |
| 明确的多规格整合候选 | 27 |
| 通过单位门禁可直接继续的候选 | 2 |
| 存在单位冲突、需复核的候选 | 28个明确候选；全量单位冲突聚类 122 个 |
| 保持独立/待复核聚类 | 881 |
| 相似候选对（待复核） | 310 |
| 服务/物流行 | 23 |
| 笼统或一批行 | 1 |
| ERPNext写入 | 0 |

首批高优先候选包括高压胶管、弹簧垫圈与平垫圈组合、PPR弯头、钢丝绳、吊带、PPR截止阀、手拉葫芦和PPR三通。它们只是整合候选，仍需在网页中查看原始行和属性后确认。

## 安全边界与下一步

首轮确定性规则只覆盖明显的类型头，例如 PPR 管件、螺栓、钢筋、灭火器、端子和高压胶管。历史别名、错别字和业务近义词暂不直接并入；下一步应在网页中按“候选族 → 原始名称 → 规格 → 单位 → GPC范围”审阅并冻结规则。冻结规则后，才可用于后续批次和多属性采购卡整合。

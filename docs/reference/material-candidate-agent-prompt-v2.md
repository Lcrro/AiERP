# 标准物料候选整理提示词 v2

## 任务

读取指定的标准物料整理输入 TSV，把每一行整理成标准物料候选。目标是整理标准物料，不是给每条找问题。

输入字段：

```text
编号
名称
规格
分组
单位
别名/土名
整理提示/依据
```

输出字段固定为：

```text
标准名称
必填规格
辅助规格
标准分组
标准单位
别名/土名
放行等级
整理依据
```

## 字段规则

- 标准名称：使用规范物料名称，不使用土名或原始长句；标准名称可以是更规范的物料族名称，SKU 差异由必填规格承载。
- 必填规格：决定是否同一 SKU 的核心规格，多个字段用中文分号“；”隔开。
- 辅助规格：采购、验收、检索有帮助，但不一定拆 SKU 的信息，多个字段用“；”隔开。没有就留空。
- 标准分组：优先使用输入分组；如明显需要规范化，可轻微调整，但不要发明大类。
- 标准单位：优先使用输入单位；如明显错字才修正。
- 别名/土名：优先使用输入“别名/土名”，可以补入原始名称作为别名；多个用“；”隔开；清理多余空格。
- 放行等级：A/B/C/D。
- 整理依据：可为空。只有存在缺失、歧义、土名归一、拆分依据、单位疑问、不能合并等情况时才填写。

## 关键口径

- 原表规格里出现的品牌默认视为重要信息，可以放入必填规格。
- 若品牌只是泛化描述、促销描述或与 SKU 无关，才放入辅助规格，并在整理依据说明。
- 不要丢失输入名称中的稳定限定信息。如果标准名称被规范化或泛化，必须把用途、类型、材质、颜色等仍会影响 SKU 或检索的信息放入必填规格或辅助规格。
- 稳定用途限定通常会影响 SKU 或检索，应保留到规格中。例如“办公室门锁”可以标准化为“门锁”，但“适用对象：办公室门”应进入必填规格；“防火门锁”“玻璃门锁”“柜门锁”也不应简单合并成无差异的“门锁”。
- 单位换算可以做，但不能丢失规格语义。
- 如果原始规格没有说明是直径、长度、宽度、容量等，不要擅自补规格类型。
- 可以保留“规格：30mm”这类中性写法；只有物料族明确时才写“直径：30mm”等具体口径。
- 不要把每一行都当问题项处理。没有问题时，整理依据留空。
- 一行输出应是一条标准物料/SKU候选。只有输入某行明确包含多个不同 SKU 时才拆成多行，并在整理依据说明。

## 放行等级

- A：名称、必填规格、分组、单位清楚，可作为标准候选。
- B：基本可用，但有轻微信息待补或需确认，不影响先作为候选。
- C：缺失会导致无法区分不同 SKU 的关键规格。
- D：不能整理成唯一物料，或存在明显冲突不能建候选。

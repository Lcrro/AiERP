# 土木/市政工程物料分类骨架与治理优先级 v0.1

本文件是一版可落地的物料主数据治理骨架，不追求一次性把所有物料洗到 100% 干净。当前目标是先把分类、命名、SKU 规格和 `needs_review` 容忍策略说清楚，让后续批量治理可以按二八原则推进。

## 1. 当前数据快照

数据口径来自：

- `data/material_master/material_master_summary.json`
- `data/material_master/governance_v0_2/material_governance_summary.json`
- `data/material_master/reclassification/material_master_reclassified_summary.json`
- `data/material_master/reclassification/material_master_reclassified.tsv`

当前主数据共 2328 个 SKU：

| 指标 | 数量 |
|---|---:|
| SKU 总数 | 2328 |
| standard | 157 |
| usable | 531 |
| needs_review | 1640 |
| auto_select_allowed | 157 |
| confirm_before_use | 531 |
| clarify_specs_before_use | 1640 |

重分类后一级类目共 20 个。SKU 数量较大的类目包括：管材管件阀门 277、电气电料 261、紧固件与连接件 204、工具量具 203、清洁办公后勤 175、液压气动 153、化工胶粘涂料 140、定制加工件 129。

## 2. 为什么不能直接套开源/公开分类库

公开分类库、国标分类、工业品电商目录和大厂目录都有参考价值，但不能直接套进当前项目。

原因有五个：

1. 目标不同。公开分类多服务于统计、监管、商品展示或电商筛选；本项目服务于采购、库存、财务统计、智能检索和自动选型控制。
2. 粒度不同。公开目录常把商品拆得很细，或按销售货架组织；ERP 主数据需要稳定编码和可复用规格模板，不能把材质、尺寸、品牌、强度等级都拆成类目。
3. 语境不同。土木/市政工程里有大量现场叫法、项目习惯、非标加工件、临采件和维修备件，公开目录无法直接判断“高压接头”到底是液压、给排水、消防还是定制加工。
4. 风险不同。主数据分类不只是好看，错误分类会影响采购询价、库存替代、自动选型、成本归集和安全合规。
5. 数据状态不同。当前 2328 个 SKU 中有 1640 个 `needs_review`，说明现阶段的核心问题不是缺少一个更大的分类表，而是名称、物料族、规格模板和人工复核边界还没有稳定。

所以本项目不寻找“完美开源物料库”，而是借鉴外部目录的结构思路，建立自己的治理口径。

## 3. 外部分类骨架如何借鉴但不照搬

可以借鉴三类外部思路：

| 来源 | 可借鉴的部分 | 不照搬的部分 |
|---|---|---|
| 国标/公开分类 | 大类边界、术语规范、编码稳定性 | 不照搬统计用途的层级，也不把工程现场口径硬塞进国标细类 |
| 工业品电商 | 搜索聚合、属性筛选、同义词和俗称承接 | 不按电商货架、品牌专区、营销类目建 ERP 分类 |
| 大厂目录/企业 MRO 目录 | 采购类目、财务统计、供应商管理口径 | 不把“常用耗材、低值易耗、某部门专用”当成物料本质分类 |

当前一级类目建议保持在 20 个左右，服务采购和财务统计；二级及以下由物料族和 SKU 规格模板控制，不让分类树无限变深。

## 4. 四级联动定义

本项目坚持：

```text
类目 -> 物料族 -> 物料名称 -> SKU 明细
```

### 4.1 类目

类目是采购、库存和财务统计层，回答“这个物料本质上属于哪一类实物”。

正例：

- 管材管件阀门
- 紧固件与连接件
- 电气电料
- 劳保防护
- 工具量具
- 液压气动

反例：

- 常用物资：这是采购频率，不是物料本质。
- 项目部材料：这是使用部门或项目，不是物料本质。
- 低值易耗品：这是财务或资产属性，不是类目。
- PPR25：这是规格或 SKU 信息，不是类目。

### 4.2 物料族

物料族是搜索聚合层和治理模板层，回答“这些物料共享什么规格字段和选型逻辑”。

正例：

- 螺丝
- 膨胀锚栓
- 液压接头
- 直接/接头
- 弯头
- 阀门
- 手套
- 钻头

反例：

- 五金：过宽，不能生成有效规格模板。
- 不锈钢：材质属性，不是物料族。
- 高压：工况或压力属性，不是物料族。
- M12*40：规格，不是物料族。

物料族要能承载同义词、别名、排除词和规格模板。例如“螺丝”族需要排除螺丝刀、螺母、垫圈、花篮螺丝等边界项；“接头”族需要按水暖、液压、气动、消防、电缆和定制加工拆分。

### 4.3 物料名称

物料名称是一望即知的稳定商品名，回答“采购人员和仓库人员看到这行，知道它大概是什么东西吗”。

正例：

- 内六角螺栓
- 自攻螺丝
- 膨胀螺栓
- PVC 弯头
- PPR 直通
- 帆布手套
- 铜球阀
- 焊条

反例：

- 螺丝：太像纯族名，无法区分螺栓、自攻、机螺钉、膨胀锚栓和套件。
- 接头：太宽，无法判断系统和连接方式。
- M12*40 镀锌 8.8级内六角螺栓：把 SKU 规格塞进了名称。
- 张工急用配件：业务场景描述，不是商品名。

少数材质或系统词如果已经是市场稳定商品名的一部分，可以保留在名称中，例如 `PVC 弯头`、`PPR 管`、`铜球阀`。但这些词仍应在 SKU 规格字段中结构化保留，避免只靠名称检索。

### 4.4 SKU 明细

SKU 明细是可采购、可库存、可替代判断的最小单位，回答“这一件具体买什么规格”。

SKU 明细才放：

- 规格、尺寸、口径、长度、厚度、截面积
- 材质、表面处理、颜色
- 品牌、型号、系列
- 强度等级、压力等级、防护等级、执行标准
- 包装规格、单位换算
- 特殊用途、适配设备、图纸号

反例：

- 物料名称只写“螺栓”，SKU 明细也缺少直径、长度、强度等级，无法采购。
- 物料名称写完整规格，SKU 字段为空，导致搜索、筛选和替代规则都失效。
- 把品牌建成类目，例如“施耐德/低压电器”，会破坏采购统计和替代策略。

## 5. 物料名称命名原则

物料名称应是稳定商品名，不是纯族名，也不塞完整规格。

建议规则：

1. 名称优先使用行业通用名或采购常用名，避免部门土话作为标准名；土话保留到别名和搜索词。
2. 名称要比物料族更具体。例如物料族为 `螺丝`，名称可为 `内六角螺栓`、`自攻螺丝`、`膨胀螺栓`。
3. 名称不要承载完整 SKU。`M12*40`、`8.8级`、`镀锌`、`品牌`、`型号`通常进入 SKU 字段。
4. 当材质或系统词本身决定商品类别时，可以进入名称。例如 `PVC 弯头`、`PPR 直通`、`帆布手套`、`铜球阀`。
5. 名称不要混入临时需求、用途说明、项目说明、供应商描述。
6. 同一物料族内要允许多个稳定名称，但每个名称都应能映射到同一套或相近规格模板。

## 6. SKU 规格字段原则

SKU 字段要按物料族定义必填和选填，不追求所有类目用同一套字段。

通用字段：

- 规格/尺寸
- 材质
- 品牌
- 型号
- 单位
- 包装规格
- 执行标准
- 备注/适配对象

典型族字段：

| 物料族 | 必填字段建议 |
|---|---|
| 螺丝/螺栓 | 螺纹规格、长度、头型、驱动型式、强度等级、材质、表面处理 |
| 膨胀锚栓 | 直径、长度、结构类型、材质、表面处理、适用基材 |
| 管材 | 材质、DN/外径、壁厚/压力等级、用途、连接方式、长度 |
| 弯头/三通/直接 | 材质、口径、连接方式、角度或结构、内外丝、压力等级 |
| 阀门 | 阀型、DN、连接方式、阀体材质、压力等级、驱动方式、密封材质 |
| 液压接头 | 螺纹规格、连接形式、适配管径、材质、压力等级、角度、密封形式 |
| 胶管总成 | 胶管规格、长度、压力等级、层数、两端接头规格、扣压形式 |
| 电线电缆 | 型号、芯数、截面积、电压等级、材质、阻燃/屏蔽要求 |
| 低压电器 | 类型、极数、额定电流、分断能力、脱扣曲线、品牌、型号 |
| 手套 | 材质、尺码、防护用途、厚度/克重、包装单位 |
| 吊装索具 | 额定载荷、长度、结构型式、材质、安全系数、标准 |
| 焊条 | 牌号、直径、材质/用途、包装重量、品牌 |

单位应逐步归一。例如 KG/kg/公斤、平方/㎡、付/副/双都可以生成候选归一表，但涉及历史采购和业务习惯时不能直接覆盖。

## 7. `needs_review` 容忍策略

`needs_review` 不是失败状态，而是治理缓冲状态。

建议口径：

1. `standard`：规格完整，允许自动选型或导入。
2. `usable`：可检索、可推荐，但采购前需要确认关键字段。
3. `needs_review`：允许搜索和提示，但不允许自动选型；触发采购时必须澄清规格。

当前 1640 个 `needs_review` 不应阻塞所有业务。治理策略是：

- 高频、高金额、工程关键、安全风险高的族先治理。
- 长尾、偶发、非标件保留 `needs_review`，等实际采购触发时再处理。
- `needs_review` 行要保留原始名称、别名、来源和缺失规格提示，避免为了“干净”丢失现场语义。
- 每批治理先产出候选规则、候选修正表和人工复核清单，不直接写 ERPNext，不直接改正式主表。

## 8. 优先治理大类

完整优先级表见：

```text
data/material_master/governance_v0_2/material_governance_priority_v0_1.tsv
```

第一批建议优先治理三个大类：

| 优先级 | 大类 | SKU | needs_review | 为什么先做 |
|---:|---|---:|---:|---|
| 1 | 管材管件阀门 | 277 | 198 | 数量最大，覆盖阀门、直接、弯头、管材、三通等工程关键物料；错误规格会造成返工、漏水、接口不匹配和安全风险。 |
| 2 | 紧固件与连接件 | 204 | 159 | 螺丝族 84 条中 83 条 needs_review，是当前最集中的 P0 问题；紧固件采购频次高，错选会影响安装和结构可靠性。 |
| 3 | 液压气动 | 153 | 124 | 液压接头和高压管路风险高，和标准管件、定制接头边界重叠；错误选型会造成泄漏、停机和安全事故。 |

第二批建议并行或紧随治理：

- 电气电料：261 个 SKU、177 个 `needs_review`，数量第二且安全合规重要；可先做电线电缆、低压电器、插头插座模板。
- 定制加工件：129 个 SKU、126 个 `needs_review`，几乎全部需要复核；应在标准管件、液压接头边界清晰后再治理，避免把标准件误留在定制族。
- 吊装索具、安全消防、焊接切割：数量不一定最大，但安全责任高，应按证书、载荷、规格、标准和有效期字段补模板。

第三批适合做规则化清洗：

- 工具量具、工具耗材：数量大，但多数规格模板明确，可以通过名称归并、尺寸字段和品牌型号字段快速提升可用性。
- 劳保防护、清洁办公后勤、包装覆盖周转：采购频次高但工程选型风险较低，可保留较多 `usable` 或 `needs_review`，实际采购触发时补齐包装、尺寸、材质。
- 设备备件、施工机具设备、电动气动工具、弱电安防：更多依赖品牌型号、适配设备或图纸，适合按采购触发治理。

## 9. 下一步执行建议

第一波不要重新发明全量分类树，直接围绕三个治理对象做可确认的候选输出：

1. 管材管件阀门：先治理阀门、直接、弯头、管材、三通，输出材质、口径、连接方式、压力等级模板。
2. 紧固件与连接件：先治理螺丝，固化长词排除规则和螺纹、长度、头型、强度等级、材质、表面处理模板。
3. 液压气动：先治理液压接头和高压管路，明确与水暖管件、气动接头、定制管路接头的边界。

这三个对象治理完，后续电气电料、定制加工件和胶管总成会少很多边界争议。

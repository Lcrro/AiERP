# 土木进销存 Agent v1.0

## 产品目标

第一版以 UP 事业部真实组织和项目主数据为基础，通过命令行 Agent 贯通：

```text
员工自然语言
  -> 意图抽取
  -> 主数据解析
  -> ToolCall 编排与执行
  -> ERPNext 员工账号
  -> 采购、库存、财务和项目成本闭环
```

首版不追求 ERPNext 全模块自然语言化。完成标准是不同岗位员工能够通过自己的 ERPNext 身份，跑通小型土木公司一日运转事件流。

## 交付阶段

1. 固化当前工程、物料和基础主数据基线。
2. 以价格就绪版 1,979 条物料为唯一发布源，完成基础主数据发布包。
3. 实现干净 ERPNext 测试账套的 `plan/apply/verify` 幂等导入器。
4. 实现 DeepSeek 意图抽取、Resolver、参数编排、结构化会话和 CLI Runtime。
5. 贯通材料申请、采购、收货退货、库存调拨领料、采购发票付款、项目成本和管理摘要。
6. 通过自然语言 Runtime 从 08:00 到 18:00 执行完整一天事件流。
7. 集中加固幂等、权限、审计、恢复和错误处理。

## 开发口径

- DeepSeek 只抽取业务意图，不填写 ERPNext 主键。
- 物料、项目、仓库、供应商、公司、日期和单位由 Resolver 解析。
- 员工 Agent 只看到业务包装工具和少量模块工具。
- ERPNext 使用当前员工身份做最终权限裁决。
- 写操作先生成草稿；提交、退货和付款等动作需要明确确认。
- 只有阻塞主流程、损坏数据、越权或串单的问题立即修复；其余问题进入缺陷队列。

## 最终验收

- 干净 ERPNext 账套可以从发布数据重复构建。
- 员工通过 CLI 输入自然语言即可创建和推进真实 ERPNext 单据。
- MR、PO、PR、退货、Stock Entry、PI、Payment 和项目成本引用完整。
- 一天事件流每个事件都有意图、解析、ToolCall、ToolResult、单据和状态记录。
- 不允许模型猜测主数据编码，也不允许权限不足时切换管理员身份。

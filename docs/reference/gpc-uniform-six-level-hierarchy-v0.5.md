# GPC 物料目录统一六层结构 v0.5

状态：已实施并通过全库核验  
日期：2026-08-28

## 统一结构

物料分类工作台中的标准类型统一位于第 6 层：

```text
1 Segment → 2 Family → 3 Class → 4 Brick
→ 5 物料族 → 6 标准类型 → 具体 SKU
```

GS1 GPC 官方四层编码和英文原文保持不变。Nexterp 新增层级继续按“父编码追加两位 `01–99`”编号；来源属性保留在数据库中，但员工界面不突出区分官方与内部节点。

## 迁移规则

- 所有直接挂在官方 Brick 下的标准类型，先插入具有业务含义的物料族。
- 已有六层分支（例如螺栓、螺钉、锚固件）保持原编号和父链。
- 若 GPC Class 下没有语义正确的官方 Brick，可增加一个本地 Brick 等价层，再按相同的物料族、标准类型结构延伸。
- 灭火器箱采用：`家庭/企业灭火器 → 灭火器附属设备 → 灭火器箱体 → 灭火器箱`，不归入灭火器组合装。
- 迁移程序必须可重复运行；第二次运行新增、重编号和重挂载数量均为 0。
- 本次只迁移本地分类节点和引用，不写 ERPNext，不改变具体 SKU 的 ERPNext Item Code、库存单位或业务状态。

## 全库核验结果

- GPC 官方节点：6,463。
- 本地 Brick 等价层：1。
- 物料族：49，其中 48 个已挂实际物料。
- 标准类型节点：85，其中 83 个已挂实际物料。
- 实际物料：259；重复物料 ID 为 0。
- 采购类型配置：83；重复配置 ID 为 0。
- 所有实际物料和类型配置均指向第 6 层标准类型。
- 缺失父级、错误父级、重复编码和遗留 `NXT-*` 引用均为 0。

# 小型土木公司一日运转模拟：员工角色表

本文记录“小型土木公司一日运转模拟”涉及的员工角色。用途是给后续 ERPNext sandbox、ToolCall 流程测试、岗位 Agent 设计提供稳定业务上下文。

## 公司设定

公司：盛拓工程有限公司

组织结构：

- 公司本部
- 三个在建项目
- 两个仓库
- 每个项目有独立项目班组

## 场景中的关键职责边界

### 项目班组

班组长只负责表达真实现场需求，例如“明天城东项目要 20 双帆布手套、10 包水泥”。系统应帮助其选对物料、补齐规格、生成材料申请。

### 项目经理

项目经理负责确认需求是否合理，关注材料是否影响进度，以及材料费用是否进入正确项目成本。

### 采购

采购负责把已提交的材料申请转成询价、采购订单或退货流程。采购不应手工重录项目需求，应该复用材料申请。

### 仓库

仓库负责库存真实性。采购到货后，仓库做采购收货；项目领料时，仓库做库存出库；发现规格不符时，仓库和采购共同触发退货。

### 财务

财务不直接处理现场领料，但需要看到采购发票、付款计划、项目成本归集和异常应付。

### 管理层

管理层不操作每张单据，主要看异常：缺料、逾期、退货、超预算、审批堆积和付款风险。

## 后续可用于测试的业务链路

| 链路 | 发起角色 | 关键单据 / 对象 |
|---|---|---|
| 项目提料 | 班组长 / 项目经理 | Material Request |
| 采购下单 | 采购主管 / 采购员 | Supplier Quotation、Purchase Order |
| 到货入库 | 仓库主管 / 仓管员 | Purchase Receipt |
| 规格不符退货 | 仓库主管 / 采购主管 / 质检员 | Purchase Receipt Return、退货原因 |
| 项目领料 | 班组长 / 仓管员 | Stock Entry、Project、Cost Center |
| 发票付款 | 财务主管 | Purchase Invoice、Payment Entry |
| 管理异常汇总 | 总经理 | 报表、审批、异常摘要 |

# 2024 采购物料主数据

这是 `data/material_purchase_2024/` 的目标整理位置。当前大部分文件仍保留在旧目录以保持脚本兼容；后续迁移时按下面规则分区。

| 子目录 | 内容 |
|---|---|
| `raw/` | 原始采购清单或从原始文件导出的轻量表，只读。 |
| `working/` | 清洗、拆分、治理、冲突处理的中间结果。 |
| `curated/` | 已整理的标准物料候选、SKU 草案、可导入候选。 |
| `exports/` | 面向 ERPNext 或 PostgreSQL 物料检索库的导入文件。 |
| `reports/` | 统计、校验、导入验证、问题清单。 |
| `batches/` | 子代理或批处理使用的输入/输出批次。 |

迁移原则：先更新脚本路径和测试，再移动文件；不要直接移动旧目录导致现有命令失效。

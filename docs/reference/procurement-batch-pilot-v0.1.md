# 龙华实际采购清单批处理试验 v0.1

## 范围

本试验只读取 `龙华项目物料待导入清单.xlsx` 的 `实际采购清单`，当前固定处理前 100 条有效业务行。`土木行业参考物料表` 不参与分析；所有输出保存在 `.runtime/material-master/batch-pilot/`，不创建或修改 ERPNext Item。

处理链为：

```text
原始行只读保留
→ 精确去重与近似规格聚类
→ DeepSeek 只提取原文事实
→ 本地 GPC Brick 候选召回
→ DeepSeek 在真实候选和固定 10+5 模板中判定
→ 程序门禁
→ 本地复核队列
```

模型不能编造 GPC 编码、模板、约束或原文没有的规格，也不能生成属性笛卡尔积。服务行和“一批/杂项”边界由确定性规则控制，模型不能把定制加工库存件改成服务。

## 运行与网页

命令行：

```powershell
python scripts\material_master\run_procurement_batch_pilot.py `
  --source "$HOME\Downloads\龙华项目物料待导入清单.xlsx" `
  --limit 100
```

只做本地预检可加 `--local-only`。工作台页面为：

```text
http://127.0.0.1:8788/procurement-batch-pilot
```

页面展示任务进度、真实 Token usage、按版本价格估算的成本，以及“已整理候选 / 新增 SKU 候选 / 新增类型候选 / 需人工复核 / 非物料服务”队列。启动任务不会触发 ERPNext 写入。

## 已验证的质量门禁

- 后续重复出现的 86 型插座和底盒自动并入已确认黄金物料；
- 多规格值规范为 `M12/M8`，不会显示 Python 列表，也不会预建所有组合；
- “加工40×40角钢1.5米”保留为定制库存候选，不误排除为服务；
- 低/中置信且选择远离候选首位的目录落点自动进入复核；
- 生成的轻量类型档案只来自可新建类型/SKU队列，复核项不提前固化；
- 浏览器筛选、API 状态回读和控制台错误检查均通过。
